The fine print most roofers won't tell you: many Texas carriers require a cosmetic-damage exclusion endorsement to apply the full impact-resistant credit — meaning dents that don't compromise the roof aren't paid. On a Class 4 system that's usually a fair trade, but you should accept it knowingly, not discover it at claim time. Ask your agent before you sign.
This is a launching pad, not a quote. The real value isn't a fixed discount — it's that a new impact-resistant roof moves you from a home carriers want to drop to one they'll compete for. That's when you shop from a position of strength.
